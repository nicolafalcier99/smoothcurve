Inter-Regular.ttf is the UI font EffectCraft embeds (assets/fonts/Inter-Regular.ttf at tag v0.24.1
of github.com/storytold/effectcraft), unmodified. Inter is by The Inter Project Authors, under the
SIL Open Font License 1.1: see OFL-Inter.txt. It is here only so that tools/render.py can draw
the panel's text the way the app does, and it is where the character widths in src/ui.js (GLYPH_W)
were read from. It is not part of the panel.
